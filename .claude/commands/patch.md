# Patch Version Bump

Bump the patch version number in pyproject.toml (e.g., 1.2.3 -> 1.2.4) and create a git tag.

## Instructions

1. Read the current version from pyproject.toml
2. Increment the patch version number
3. Update the version in pyproject.toml
4. Create a git tag with the new version (e.g., v1.2.4)
5. Show the new version and ask if the user wants to push the tag
