# Minor Version Bump

Bump the minor version number in pyproject.toml (e.g., 1.2.3 -> 1.3.0) and create a git tag.

## Instructions

1. Read the current version from pyproject.toml
2. Increment the minor version number and reset patch to 0
3. Update the version in pyproject.toml
4. Review CHANGELOG.md and update it with the new version and changes from git commits since the last version
5. Create a git tag with the new version (e.g., v1.3.0)
6. Show the new version and ask if the user wants to push the tag
