# Major Version Bump

Bump the major version number in pyproject.toml (e.g., 1.2.3 -> 2.0.0) and create a git tag.

## Instructions

1. Read the current version from pyproject.toml
2. Increment the major version number and reset minor and patch to 0
3. Update the version in pyproject.toml
4. Create a git tag with the new version (e.g., v2.0.0)
5. Show the new version and ask if the user wants to push the tag
